# TaskFlow Premium Frontend

Premium responsive React + TypeScript frontend for TaskFlow.

## Included
- Functional email/password auth UI wired to the TaskFlow REST API
- Google Identity Services button wired to `POST /api/auth/google`
- Real light / dark / system theme switching with persistence
- Larger, high-visibility typography
- Responsive sidebar + mobile navigation
- Command palette (`Ctrl/Cmd + K`)
- Quick task creation (`N`)
- Search (`/`)
- Task CRUD interactions wired to the API
- Analytics and dashboard views
- Working appearance, notification preference and security UI
- Profile/password settings wired to the backend endpoints
- Loading, empty, error and success states
- Reduced-motion support

## Run

```bash
npm install
npm run dev
```

Create `.env` from `.env.example`.

## API

Default: `http://localhost:5000/api`

Expected backend endpoints include auth, tasks, profile/password and Google credential verification.
